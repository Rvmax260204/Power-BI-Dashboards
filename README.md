# Power BI Dashboards Portfolio

This repository showcases my data analytics and business intelligence projects built using **Microsoft Power BI**. It contains interactive dashboards designed to transform data into meaningful business insights and support data-driven decision-making.

## Projects

### 1. HR Analytics Dashboard
Analyzes workforce data, employee attrition, headcount, and HR performance indicators to support workforce planning and employee retention.

### 2. Sales Analytics Dashboard
Visualizes sales performance, revenue trends, and business metrics to identify patterns and support sales-related decisions.

### 3. Supply Chain Analytics Dashboard
Focuses on supply chain performance and operational insights to help monitor business processes and identify improvement opportunities.

## Tools & Skills
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- KPI Development
- Interactive Dashboards

## How to Explore
Download the `.pbix` file for any project and open it using **Microsoft Power BI Desktop** to explore the visualizations and interact with the report.

## Objective
To develop practical business analytics skills by building dashboards that present complex data in a clear, structured, and decision-oriented format.
